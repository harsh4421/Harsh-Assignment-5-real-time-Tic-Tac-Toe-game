# Real-Time Tic Tac Toe

A real-time two-player Tic Tac Toe game built with Node.js, Express, Socket.io, and Supabase/PostgreSQL.

## Features
- Real-time multiplayer rooms
- Server-authoritative turn validation
- X/O player assignment
- Win and draw detection
- Game reset
- Persistent match history through Supabase
- REST endpoint for recent game history
- Responsive frontend

## Setup

### 1. Install dependencies
```bash
npm install
```

### 2. Configure environment
Create `.env` from `.env.example`:
```env
PORT=3000
SUPABASE_URL=your_supabase_project_url
SUPABASE_KEY=your_supabase_key
```

### 3. Create the Supabase table
Run this SQL in Supabase SQL Editor:
```sql
create table if not exists games (
  id bigint generated by default as identity primary key,
  player_x text,
  player_o text,
  winner text,
  is_draw boolean default false,
  moves jsonb,
  created_at timestamptz default now()
);
```

### 4. Start
```bash
npm run dev
```
Open the URL printed by the server.

## API
`GET /api/health` checks the server.

`GET /api/history` returns the latest completed games. Supabase must be configured.

## How to Play
1. Enter your name and a room code.
2. Share the same room code with another player.
3. The first player becomes X and the second becomes O.
4. Players take turns until there is a winner or draw.
5. Use **New Round** to reset the board while keeping both players in the room.

## Deployment
Set `SUPABASE_URL`, `SUPABASE_KEY`, and `PORT` as environment variables on your hosting platform. The app serves the frontend and Socket.io connection from the same Express server.
